# Gofra Documentation

Documentation for Gofra programming language

Available live at [Github Pages](https://gofralang.github.io/docs)

## Quick Start

### Requirements

```bash
# Install via poetry
poetry install
```

### Local preview

```bash
poetry run mkdocs serve
```

### Build

```bash
poetry run mkdocs Build
poetry run mkdocs gh-deploy # Owners deploy
```
