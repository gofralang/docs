# Targets

List all current compilation targets via `gofra targets`

Gofra compiles to the following targets:

| Target                  | Architecture | OS      | Status       |
| ----------------------- | ------------ | ------- | ------------ |
| `amd64-apple-darwin`    | x86_64       | MacOS   | stable       |
| `arm64-apple-darwin`    | ARM64        | MacOS   | experimental |
| `amd64-unknown-linux`   | x86_64       | Linux   | experimental |
| `amd64-unknown-windows` | x86_64       | Windows | experimental |
| `wasm32-unknown-none`   | WASM32       | -       | experimental |
